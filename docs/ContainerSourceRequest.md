# ContainerSourceRequest

## Enum Variants

| Name | Description |
|---- | -----|
| ContainerSourceRequestOneOf | Where the container image comes from. Send exactly one of &#x60;image&#x60; or &#x60;git_repository&#x60;; both, or neither, returns 400. A &#x60;null&#x60; &#x60;image&#x60; or &#x60;git_repository&#x60; counts as not sent. - &#x60;image&#x60;: an image from a container registry, like the flat &#x60;registry_id&#x60;, &#x60;image_name&#x60; and &#x60;tag&#x60; fields. - &#x60;git_repository&#x60;: a Git repository with a Dockerfile. Qovery builds the image from the deployed commit. Accepted on update (&#x60;PUT /container/{containerId}&#x60;) only: sending it on create returns 400.  Switching the source keeps the same container: its id, Kubernetes names, volumes and built-in variables. The switch does not deploy; the next deployment uses the new source.  Rules: - On update (&#x60;PUT /container/{containerId}&#x60;), &#x60;source&#x60; is ignored when it repeats the stored source, and the flat &#x60;registry_id&#x60;, &#x60;image_name&#x60; and &#x60;tag&#x60; fields are ignored when every one sent equals the image the container runs (the &#x60;registry.id&#x60;, &#x60;image_name&#x60; and &#x60;tag&#x60; that GET returns). A body built from the GET response is accepted as is; only the side the client changed is applied. - On update, &#x60;source&#x60; and the flat fields both asking for a change returns 400, unless both name the same image. This includes a &#x60;source.git_repository&#x60; change sent with changed flat fields. On create, sending &#x60;source&#x60; together with the flat fields still returns 400. - On update of a container with an image source, &#x60;source.image.registry_id&#x60; may be omitted: the stored registry is kept. Switching a container with a Git repository source back to an image, and create, require it. - When &#x60;source&#x60; is not sent, the stored source is kept. Flat fields never switch the source. - On a container with a Git repository source, flat fields equal to the &#x60;registry.id&#x60;, &#x60;image_name&#x60; and &#x60;tag&#x60; that GET returns are accepted and change nothing; different values return 400 unless &#x60;source.image&#x60; asks for the same image. A deployment that finishes between the GET and the PUT changes these values: get the container again and retry. Send &#x60;source.image&#x60; to switch back to an image. - A &#x60;git_repository&#x60; source requires &#x60;auto_deploy&#x60; and &#x60;auto_preview&#x60; to be false or not specified: 400 otherwise. When not specified on a switch to &#x60;git_repository&#x60;, both are set to false.  |
